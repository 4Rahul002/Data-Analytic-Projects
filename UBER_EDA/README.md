# Uber Supply-Demand Gap Analysis

## Overview

This project analyzes the supply-demand gap for Uber rides, focusing on identifying patterns and trends in ride requests, cancellations, and availability. The analysis includes visualizations such as treemaps, bar charts, and time series plots to provide insights into the data.

## Features

- **Data Analysis**: Identify trends and patterns in ride requests and cancellations.
- **Visualizations**: Interactive visualizations to explore the data.
- **Insights**: Actionable insights to optimize driver supply and meet customer demand.
